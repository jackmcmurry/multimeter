    What this is

    A live tracker for bitcoin and the Nasdaq, with the statistics that make the comparison mean something. Bitcoin refreshes every 45 seconds. Nasdaq figures refresh about every 15 minutes during US market hours, and the statistics are recomputed from daily closes after each session.

    Instruments

    BTC / USD — spot bitcoin, volume-weighted across the exchanges CoinGecko tracks. Trades every calendar day.

    ^IXIC — the Nasdaq Composite, roughly 3,000 listed securities. An index level, not a tradable price.

    QQQ — Invesco QQQ Trust, the ETF tracking the Nasdaq-100. It stands in for ^NDX, which the free data plan does not carry.

    Stock of the week

    A job runs each Monday before the open, scans a fixed 15-name Nasdaq-100 universe, and stores whichever name posted the largest absolute five-session move. The price beside it refreshes with the Nasdaq quotes.

    Absolute rather than largest gain, deliberately. Ranking by best performer would read as a tip. This reports what moved, in either direction — it is not a recommendation.

    Method

    Correlation and beta use log returns taken after intersecting both instruments on dates each actually traded. Bitcoin trades weekends and the index does not, so without that step BTC's Monday return spans one day while the index's spans three.

    Beta is BTC regressed on the index — the slope of the line through the return scatter. R² is the share of BTC's variance the index explains; a high beta with a low R² is a loose relationship, not a tight one.

    Volatility is the sample standard deviation of the 30-session window, annualized by √252. Drawdown runs on each instrument's own history, since a drawdown belongs to one asset's own path.

    Sources

    CoinGecko's public API for bitcoin spot and its chart, called directly from your browser. Financial Modeling Prep for the ^IXIC quote and daily closes, BTCUSD daily closes and the weekly stock scan; Alpha Vantage for QQQ. Those two need API keys, which cannot ship in a public page, so a scheduled GitHub Action calls them with keys kept as repository secrets and publishes only the results. The market-open indicator is computed in your browser from NYSE hours and holidays.
